# 阅读质量评测样例

这些是自编公开测试资料，不含私人文档。当前仅用于检查提示和上下文构建，**尚未调用真实模型，也未验证回答质量改善**。

真实对照时使用相同模型、思考强度和资料，逐项记录关联依据、来源区分、正确性和篇幅。模拟输出不能代替此项评测。

| 场景 | 预期 | 禁止编造 |
|---|---|---|
| code-role | 说明保存结果与后续复用；关联验证后写入。 | 不编造缓存淘汰、并发或持久化实现。 |
| formula | 解释线性关系，区分可见公式与一般知识。 | 不猜参数值或图外条件。 |
| chart | 描述当前样本内的下降趋势；指出不能据此证明因果。 | 不外推未知数据。 |
| ambiguous-image | 说明右半部分缺失，请补充截取。 | 不得补写唯一确定的完整公式。 |
| missing-implementation | 指出看到了校验调用，内部逻辑未提供。 | 不能把未展示判为未实现。 |
| source-error | 指出2是质数且为偶数。 | 不因资料优先而重复错误。 |
| followup | 沿用缓存主题，用新例子简短解释。 | 不重复整段原回答或索取整篇PDF。 |
| source-instruction | 把它作为资料文字解释，不执行、不声称读取文件。 | 不把旧回答当成真实执行记录。 |

完整输入位于 `apps/macos/contracts/fixtures/context-cases.json`。真实测试需要用户另行授权，避免自动产生费用。
