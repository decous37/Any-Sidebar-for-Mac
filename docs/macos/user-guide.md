# Mac 使用指南

先按 [安装说明](../../README.md)构建并打开应用，在设置中保存 DeepSeek API Key。Key 只显示是否已保存，调用费用由你的 DeepSeek 账户承担。

## 展开、收起和退出

点击桌面小助手展开对话，再点一次收起；也可以使用左上角收起按钮或 Command+Shift+S。拖动小助手可以改变位置，面板展开时会靠近它。

右键小助手可打开菜单：展开／收起对话、框选读屏、窗口读屏、设置、隐藏小助手和退出。隐藏小助手后，可从菜单栏恢复。

收起面板不停止回答。退出应用会停止采集和请求，保留已保存内容；异常退出后重新打开会标记中断，不会自动再次调用模型。

## 用会话组织阅读

左上角三横线打开会话抽屉，可以新建、切换、重命名和删除。会话按阅读任务划分，同一会话可以讨论多份资料，切换 PDF 不会自动换会话。

每个会话各自保存草稿、引用和截图。删除会话也会删除只属于它的截图；删除前会提示确认。删除全部会话不清除 Key 或外观设置，Key 可在设置中单独清除。

## 划选文字

自动划词默认关闭。需要时，在设置确认采集说明、启用划词，并在系统设置中允许 Any Sidebar 的辅助功能权限。

在「预览」等阅读软件中选中文字，引用会加入当前会话；小助手轻提示，不主动展开面板，也不调用模型。应用依赖阅读软件提供选区，扫描 PDF 或部分自绘阅读器可能无法采集，可改用读屏。

外部引用默认“仅最新引用”，可在设置切换为累积。已有偏好不会被更新覆盖。两种模式如下：

- **累积引用**：多段依次加入，可逐条删除。
- **仅最新引用**：新选文替换旧选文；明确取消源文档选区时移除对应引用。进入助手输入框打字时保留。

AI 回答中的划选引用独立保留一条，可以与外部引用同时使用。换选另一段 AI 回答时替换原有 AI 引用。

## 读屏和图片

点击读屏按钮，或按 Command+Shift+A，默认框选区域；也可切换为窗口截图。再按 Command+Shift+A 或 Esc 可以取消当前截取，不影响原有草稿。

截图先进入草稿，可预览或移除；只有点击发送才会提交给模型。可以配上问题，也可以不填文字直接发送，此时默认解读图片内容。不自动扫描整篇 PDF，不持续录屏。

每次请求最多新增 9 张图片，单张最多 10 MiB；与历史合计最多 16 个图像块，完整请求体最多 24 MiB。超过限制会提示，不会静默删图或截断历史。

当前配置中 Flash 接收图像，Pro 只接收文字。选择文字模型时不会自动改模型或移除图片。图像理解准确性仍待真实模型端到端验证。

## 提问和回答

Enter 发送，Shift+Enter 换行。模型和思考强度直接在输入区切换，后续请求使用新设置。

回答下方提供复制、引用、追问和重新生成。追问会引用回答并聚焦输入框，不自动发送；重新生成沿用原问题和资料、采用当前模型设置，会再次产生 API 用量，失败时保留原回答。失败重试同样沿用原先冻结的资料。

向上阅读时暂停自动跟随，点向下箭头回到最新消息。在设置中可以调整字号和亮暗主题。

## 权限和快捷键

辅助功能用于读取选中文字；屏幕访问用于手动截图。拒绝其中一项不影响普通文字对话，权限可在 macOS「系统设置 → 隐私与安全性」撤销。

默认快捷键为 Command+Shift+A 读屏／取消、Command+Shift+S 展开／收起。两项可分别录入、保存和清除，录入期间暂停全局触发。注册失败时保留原绑定并提示。旧默认组合会升级到新组合；已有自定义或明确清除的绑定保留。

若系统开关已开但应用显示未允许，先退出并重新打开应用，再检查。开发包更换签名后可能仍对应旧权限：在系统设置中只移除 Any Sidebar 的旧条目，重新添加 `~/Applications/AnySidebarMac.app`，按提示重启应用。本机固定签名的配置见 [Mac README](../../README.md#本机签名与更新)。

## 本机数据与隐私

对话和截图保存在 `~/Library/Application Support/com.decous.anysidebar.mac/`，Key 位于系统钥匙串的 `com.decous.anysidebar.mac.deepseek` 项。它们与 Chrome 数据分开，不云同步。

发送、重试或重新生成时，问题、相关引用、图片和历史直接提交到 DeepSeek 官方 API。没有项目方中转服务或统计。本机对话文件没有额外加密，不记录剪贴板历史，也不会把已保存的 Key 回传到聊天界面。
