Any Sidebar for Mac

对话、引用和截图保存在这台 Mac。API Key 存入 macOS 钥匙串，不会提供给对话页面。

自动划词须经你同意并启用，使用辅助功能读取前台阅读区的选中文字，不扫描整个文档，不记录输入或剪贴板历史。

读屏仅由按钮或快捷键触发，不持续录屏。截图先保存在草稿，你发送问题后，问题、相关引用、图片及会话历史才直接提交至 DeepSeek 官方 API，并产生你账户的 API 用量。没有中转服务、统计或云同步。

你可以关闭采集、移除截图、删除任务或清除 Key。权限可在系统设置中撤销。本机文件未额外加密，设备安全由 macOS 和你的账户保护；模型可能出错，请核对重要结论。
